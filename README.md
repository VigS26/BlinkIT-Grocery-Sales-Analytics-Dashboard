# 🛒 BlinkIT Grocery Sales & Analytics Dashboard

An end-to-end data analytics project examining sales performance, customer preferences, product categories, and outlet attributes for **BlinkIT**. This project provides actionable insights into revenue drivers, item distribution, and outlet tier performance to optimize inventory, marketing, and operational efficiency.

---

## 📌 Project Overview

BlinkIT is a fast-growing quick-commerce platform delivering groceries and daily essentials. The objective of this project is to analyze transaction data across multiple retail outlets, identify key growth opportunities, and evaluate operational metrics like item visibility, fat content preferences, and outlet location impacts.

## 🔍 Key Insights & Analysis

### 1. Sales by Item Fat Content
* **Low Fat Products:** Account for over **64%** of overall sales ($776.3K total across normalized categories), indicating a strong consumer preference for healthier alternatives.
* **Regular Fat Products:** Represent approximately **35.4%** ($425.3K) of total revenue.

### 2. Performance by Outlet Type
* **Supermarket Type 1:** Dominates overall sales volume, contributing **$787,549.89 (~65.5% of total sales)** across 5,577 items.
* **Grocery Stores:** Generated **$151,939.14** with an average order value of **$140.29**.
* **Supermarket Type 2 & Type 3:** Generated **$131.4K** and **$130.7K** respectively, maintaining consistent average sales around **$140 - $141**.

### 3. Revenue Breakdown by Location Tier
* **Tier 3 Outlets:** Highest revenue generator at **$472,133.03 (39.3%)**, driven by volume across larger outlets.
* **Tier 2 Outlets:** Contributed **$393,150.65 (32.7%)**.
* **Tier 1 Outlets:** Accounted for **$336,397.81 (28.0%)**.

### 4. Top Performing Product Categories
1. **Fruits & Vegetables:** $178,124.08 (1,232 items sold)
2. **Snack Foods:** $175,433.92 (1,200 items sold)
3. **Household Items:** $135,976.53 (910 items sold)
4. **Frozen Foods:** $118,558.88 (856 items sold)
5. **Dairy:** $101,276.46 (682 items sold)
